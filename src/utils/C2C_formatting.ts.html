How

Context

Provides the core formatting logic for displaying numeric values throughout the application. Used for metrics, counts, statistics, or any numeric display where space is limited or readability is important.

What

Array filter method using Boolean constructor as predicate to remove falsy values

Why

Concise, idiomatic way to remove all falsy values (false, null, undefined, 0, '', NaN) from array. The Boolean constructor as a filter predicate is a well-known JavaScript pattern. More readable than custom filter function. Efficiently removes conditional class names that evaluated to false. Single-pass operation that's performant.

How

filter() calls Boolean constructor for each array element. Boolean(value) returns true for truthy values, false for falsy values. filter() keeps only elements where predicate returns true. This removes all falsy values in one operation. The Boolean constructor acts as a type coercion function.

Context

Filters out all falsy values from the classes array, keeping only actual string class names. This removes false, null, undefined values that come from conditional expressions like 'condition && "className"'.

Alternatives
