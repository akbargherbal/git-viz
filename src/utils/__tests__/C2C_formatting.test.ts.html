Testing Patterns

.toBe("1.5M")

What

Matcher that performs strict equality comparison (===) between actual and expected values

Why

toBe is used for primitive values (strings, numbers, booleans) and reference equality checks. It's the most performant matcher for simple comparisons and makes test intent clear - we expect exact equality.

How

Internally uses Object.is() for comparison, which is similar to === but handles NaN and -0/+0 differently. For strings and numbers, it's effectively strict equality.

Context

Used consistently throughout the file to verify string outputs from formatNumber and cn functions match expected string values exactly.

Alternatives

Use toEqual for deep equality of objects/arrays; use toStrictEqual for stricter object comparison; use toMatch for regex patterns; use toContain for partial matches
