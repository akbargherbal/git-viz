TypeScript/Type System
Advanced 
pluginStates: Record<string, Record<string, unknown>>;

What

Nested Record type creating a two-level map structure where plugin IDs map to objects containing arbitrary key-value pairs

Why

Record<K, V> is TypeScript's utility type for object with string keys and specific value type. Nested Records create a plugin registry where each plugin can store its own state object. Using 'unknown' for inner values provides type safety (safer than 'any') while allowing plugins to store any data structure. This pattern enables a plugin system where each plugin manages its own state independently.

How

Record<string, T> is equivalent to { [key: string]: T }. The outer Record maps plugin IDs (strings) to state objects. The inner Record maps state keys (strings) to unknown values. Unknown type requires type checking before use, unlike any.

Context

Storage for plugin-specific state where each plugin (identified by string ID) can maintain its own state object with arbitrary properties. Enables extensible plugin architecture without coupling store to specific plugin implementations.

Alternatives

Map<string, Map<string, unknown>>; object with index signature; separate stores per plugin; generic type parameter; using any instead of unknown; WeakMap for automatic cleanup
