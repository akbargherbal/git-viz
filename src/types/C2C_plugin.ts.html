ES6 named import syntax with curly braces containing comma-separated type names. The relative path "./domain" resolves to a sibling file in the same directory. TypeScript treats these as type-only imports automatically when used only in type positions.

Importing foundational domain types that represent repository metadata, directory structure, and activity data - the core data structures that plugins will work with

Alternatives

Import type syntax 'import type { ... }' to make type-only explicit; namespace import 'import * as Domain from "./domain"'; individual import statements; inline type definitions

CONCEPT-011

TypeScript/Type System
Intermediate 
(raw: any) => any

What

Use of TypeScript's 'any' type which disables type checking for that value, allowing any type to be assigned

Why

Necessary here because the raw dataset shape is unknown and varies by dataset type. Provides maximum flexibility for plugin authors to work with different data structures. Trade-off between type safety and flexibility.

How

The 'any' type is TypeScript's escape hatch that opts out of type checking. Any value can be assigned to 'any', and 'any' can be assigned to any type. No compile-time type checking occurs.

Context

Used for transform function parameter and return type because datasets have varying structures that can't be known at compile time. Plugins will handle type narrowing at runtime.

Alternatives

Generic type parameter '<T>(raw: T) => T'; unknown type for safer any 'unknown'; specific union types if data shapes are known; branded types; use type guards
