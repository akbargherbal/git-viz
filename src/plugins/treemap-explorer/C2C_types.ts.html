Required property that can be either a string or null, using union type

Why

How

Union type combining string and null; property is required but value can be null; TypeScript enforces null checks before using as string

Context

Defines 'selectedFile' as either a file path string or null when no file is selected in the treemap

Optional property (selectedFile?: string); undefined instead of null; empty string for no selection; separate hasSelection boolean
