toBe uses Object.is() to check if two values are the exact same reference. This is important for verifying that a method returns the same object rather than a copy, which can affect performance and mutation behavior.

How

The toBe matcher compares references using Object.is(), which checks if both values point to the same location in memory. For objects/arrays, this only passes if they're the exact same instance.

Context
