JavaScript/ES2020 Features
Intermediate 
const threshold = state.healthThreshold ?? 100;

What

Uses the nullish coalescing operator (??) to provide a default value when the left operand is null or undefined

Why

Provides a safe default value (100) when healthThreshold is not set in state. The ?? operator only uses the default for null/undefined, unlike || which would also use default for 0, false, or empty string. This is more precise than logical OR for default values.

How

The ?? operator checks if left side is null or undefined. If so, it returns the right side (100). Otherwise, it returns the left side value. This is evaluated at runtime.

Context

Ensures there's always a valid threshold value for filtering. If user hasn't set a health threshold, defaults to 100 (show all files). This prevents errors from undefined threshold values.

Alternatives

Logical OR operator 'state.healthThreshold || 100' (but treats 0 as falsy); ternary operator 'state.healthThreshold !== undefined ? state.healthThreshold : 100'; optional chaining with default; default parameter value

d3.interpolate("#b91c1c", "#dc2626")(score / 20)

What

Uses D3's interpolate function to create a smooth color transition between two hex colors, then calls the resulting interpolator with a normalized value

Why

Creates smooth color gradients within each health score range. D3's interpolation handles the complex math of blending RGB values. The two-step process (create interpolator, then call it) allows for efficient reuse of interpolators. This produces visually pleasing color transitions that make the visualization more informative.

How

d3.interpolate(a, b) returns a function that takes a value between 0 and 1 and returns a color between a and b. The expression (score / 20) normalizes the score to 0-1 range for the current tier. The interpolator is immediately invoked with this normalized value to get the final color.

Context

For the 0-20 score range, interpolates between dark red (#b91c1c) and red (#dc2626). The score is divided by 20 to normalize it to 0-1 range. A score of 0 returns the first color, 20 returns the second color, and values in between get blended colors.

Mathematics/Data Transformation
Intermediate 
(score - 20) / 20

What

Mathematical expression that normalizes a value from a specific range (20-40) to the 0-1 range

Why

D3's interpolate function expects a value between 0 and 1. This formula converts a score in the 20-40 range to 0-1: score 20 becomes 0, score 40 becomes 1, and values in between are proportionally scaled. This normalization is essential for correct color interpolation.

How

Subtracts the range minimum (20) to shift the range to start at 0, then divides by the range width (20) to scale to 0-1. For score=30: (30-20)/20 = 10/20 = 0.5, which is the midpoint.

Context

Used in the second tier (20-40 range) to normalize scores for color interpolation. Each tier uses a similar formula with different offsets and divisors to normalize its specific range.

d3.interpolate returns a function. The parentheses immediately after create a function call, passing the normalized score. This is function composition: the result of one function call is immediately used to call another function.
