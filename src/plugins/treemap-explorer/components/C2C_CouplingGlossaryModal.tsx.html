What

Comma after the last element in an array or object literal, which is syntactically valid in modern JavaScript

Why

Makes version control diffs cleaner when adding new items - you only see the new line added, not a modification to the previous line to add a comma. JavaScript parser ignores trailing commas in arrays and objects (as of ES5). The comma after the last element is simply discarded during parsing. This is different from older JavaScript versions where trailing commas caused syntax errors.

Context

Used consistently throughout the data structure for all arrays and objects. This makes the code easier to maintain and produces cleaner git diffs when terms or properties are added or reordered.

Alternatives
