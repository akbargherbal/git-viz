Parent passes callback functions as props. Child calls callbacks when user interacts. Parent receives callback calls and updates state. New state flows back down as props.

Context

onStateChange allows filter changes to propagate to parent. onClose signals parent to close filter panel. Parent controls state and visibility, child just triggers actions.

Alternatives

Context for state; Redux/state management; custom hooks; event emitters; refs; global state
