What

Why

Creates a new object combining properties from multiple sources without mutating originals. Right-most spreads take precedence, allowing overrides pattern. This is immutable and creates shallow copies.

How

The spread operator (...) expands object properties into the new object literal. When properties conflict, the last one wins. This creates a new object reference, leaving originals unchanged.

Context
