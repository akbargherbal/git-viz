Testing/DOM Querying
Intermediate 
screen.getByText(/Jan.*1.*2023/i)

What

Query method that finds elements by text content using regular expression for flexible matching

Why

Regex allows flexible text matching without exact string match, handles whitespace variations, ignores formatting differences, and makes tests more resilient to minor text changes. Case-insensitive flag (i) adds more flexibility.

How

getByText accepts string or regex. Regex /Jan.*1.*2023/i matches 'Jan', followed by any characters (.*), then '1', any characters, then '2023'. The 'i' flag makes it case-insensitive.

Context

Finding date text that might be formatted as 'Jan 1, 2023' or 'Jan. 1 2023' or similar variations. The regex handles different formatting while ensuring key parts are present.

Alternatives

Exact string match 'Jan 1, 2023'; getByText with function matcher; data-testid attribute; getByRole with name; custom text matcher
