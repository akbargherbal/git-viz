What

Why

Ensures intensity stays in valid range [0, 1] for the D3 color scale. Without clamping, coupling values above 0.8 would produce intensity > 1, which could cause unexpected behavior in the scale. Clamping creates a saturation effect where very high coupling values all map to the same maximum color.

How

Math.min returns the smallest of its arguments. Here it compares 'coupling / 0.8' with 1. If coupling is 0.8 or higher, intensity becomes 1. If coupling is less than 0.8, intensity is the ratio (e.g., 0.4/0.8 = 0.5).

Context

Normalizes coupling values to 0-1 range for D3 color scale input. The division by 0.8 means coupling of 0.8 maps to intensity 1.0 (full saturation), and values above 0.8 are clamped to 1.0.

Alternatives
