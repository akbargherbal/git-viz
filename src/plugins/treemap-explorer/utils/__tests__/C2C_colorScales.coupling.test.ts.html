What

Import statement using '@/' path alias to reference test utilities from project root

Why

Provides consistent, absolute-style imports that avoid brittle relative paths like '../../../test-utils'. Makes refactoring easier and improves readability. The '@/' alias typically maps to 'src/' directory, configured in tsconfig.json and build tool.

How

Build tool (Vite/Webpack) and TypeScript resolve '@/' to configured base directory via tsconfig.json paths mapping and bundler alias configuration. The import is transformed at build time to actual file path.

Context

Importing test framework functions (describe, it, expect) from centralized test utilities module. This suggests the project has a custom test-utils module that likely re-exports Vitest or Jest functions with possible custom extensions.

Alternatives

Relative import '../../../../../test-utils'; different alias convention like '~/' or 'src/'; direct import from test framework 'vitest' or 'jest'; no alias with full relative paths
