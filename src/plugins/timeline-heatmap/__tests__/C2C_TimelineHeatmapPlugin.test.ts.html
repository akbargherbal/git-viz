Testing/Test Framework

import { describe, it, expect, beforeEach, afterEach, vi } from "vitest";

What

Named imports of core Vitest testing utilities including test organization functions (describe, it), assertion library (expect), lifecycle hooks (beforeEach, afterEach), and mocking utilities (vi)

Why

Vitest is a fast, Vite-native unit test framework that provides Jest-compatible API. Importing these functions enables: (1) Test suite organization with describe/it blocks; (2) Assertions with expect; (3) Setup/teardown with lifecycle hooks; (4) Mocking capabilities with vi. This provides a complete testing toolkit in a single import.

How

Vitest exports these functions as named exports. The 'describe' and 'it' functions create test suites and individual tests. 'expect' provides assertion methods. 'beforeEach' and 'afterEach' run before/after each test. 'vi' is the mocking utility namespace similar to Jest's 'jest' object.

Context

Used throughout the test file to structure tests, make assertions, manage test lifecycle, and create mocks. This is the foundation of the entire test suite.

Alternatives

Jest (similar API but slower, not Vite-native); Mocha + Chai (separate assertion library); Node's built-in test runner; Testing Library without a framework; AVA; Tape
