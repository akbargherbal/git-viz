Algorithm/Mathematics
Advanced 
private static scoreChurn(churnRate: number): number {
  if (churnRate <= 0.3) return 90 + (0.3 - churnRate) * 33; // 90-100
  if (churnRate <= 0.5) return 70 + (0.5 - churnRate) * 100; // 70-90
  if (churnRate <= 0.7) return 40 + (0.7 - churnRate) * 150; // 40-70
  return Math.max(0, 40 - (churnRate - 0.7) * 133); // 0-40
}

What

Function that maps input value (churn rate 0-1) to output score (0-100) using different linear formulas for different input ranges

Why

Creates non-linear scoring that reflects domain knowledge: low churn (0-30%) is excellent (90-100 score), moderate churn (30-50%) is acceptable (70-90), high churn (50-70%) is concerning (40-70), very high churn (70-100%) is critical (0-40). The piecewise approach allows different slopes for different ranges, making the scoring more nuanced than a simple linear mapping.

How

Uses cascading if statements to check ranges. Each range has its own linear formula: base score + (distance from threshold) * slope. The multipliers (33, 100, 150, 133) control how quickly score changes within each range. Math.max(0, ...) ensures score never goes negative.

Context

Converts raw churn rate (0-1) into a health score (0-100). Inverted relationship: lower churn = higher score. The four ranges create a graduated scoring system that penalizes high churn more severely.

Alternatives

Single linear formula; exponential/logarithmic curve; lookup table; polynomial function; sigmoid function; step function with discrete ranges

Algorithm/Mathematics
Advanced 
return Math.min(100, 90 + Math.log10(uniqueAuthors - 4) * 10);

What

Mathematical formula using logarithm to create diminishing returns effect, where additional authors provide progressively smaller score increases

Why

Reflects real-world dynamics: going from 1 to 2 authors is huge improvement (30 to 60 score), but going from 10 to 11 authors provides minimal additional benefit. Logarithmic scale captures this diminishing returns pattern. Prevents score from growing unboundedly with author count.

How

Math.log10() calculates base-10 logarithm. For 5 authors: log10(5-4) = log10(1) = 0, score = 90. For 14 authors: log10(14-4) = log10(10) = 1, score = 100. The logarithm grows slowly, creating the diminishing returns effect. Math.min(100, ...) caps at 100.

Context

Applied to author diversity scoring for 5+ authors. After 5 authors, additional contributors provide diminishing value. The logarithmic scale reflects that 10 authors isn't twice as good as 5 authors.

Alternatives
