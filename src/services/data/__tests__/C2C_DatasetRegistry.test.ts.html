What

Configured alias that maps '@/' to a base directory (typically 'src/' in project root), used here to import test utilities

Why

How

Configured in tsconfig.json paths mapping ('"@/*": ["src/*"]') and bundler/test runner configuration. The build tool, TypeScript, and test runner all resolve '@/' to the configured directory

Context

Importing test framework utilities (describe, it, expect) from centralized test-utils module using path alias, avoiding relative path navigation from nested __tests__ directory

Alternatives

Relative imports like '../../../test-utils'; absolute imports without alias; importing directly from testing library like 'vitest' or 'jest'; different alias conventions like '~/' or 'src/'
