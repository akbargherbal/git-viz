const aPartners = index.get("src/A.ts")?.partners;

What

Optional chaining operator (?.) that safely accesses nested properties, returning undefined if any part of the chain is null or undefined

Why

Optional chaining prevents runtime errors when accessing properties on potentially null/undefined values. In tests, it's useful for safely extracting nested data before asserting on it. If the chain breaks, the variable becomes undefined, which can then be checked with toBeDefined() or similar assertions.

How

The ?. operator checks if the left side is null/undefined before accessing the right side. If null/undefined, it short-circuits and returns undefined. Otherwise, it accesses the property normally. This can be chained multiple times: obj?.prop1?.prop2?.prop3

Context

Safely accessing the partners property from the result of index.get(). If the file doesn't exist in the index, get() returns undefined, and the optional chaining prevents a TypeError, resulting in aPartners being undefined.

Alternatives
