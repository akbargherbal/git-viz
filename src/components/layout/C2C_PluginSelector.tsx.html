Why

Capture phase listeners fire before bubble phase; catches scroll events on any element, not just window; ensures dropdown closes on any scroll (window, div, etc.); more reliable than bubble phase for scroll events.

Default export statement that exports the component as the module's default export

Why

Allows importing without curly braces; common pattern for components; one default export per module; can be renamed on import; works alongside named exports.

How

export default keyword exports a single value as the module's default. Importers can use any name: 'import MySelector from "./PluginSelector"'. Different from named exports which require matching names.

Context

Exports PluginSelector as default in addition to the named export. Provides flexibility for importers to use either import style. Common pattern to support both import styles.

Alternatives

Named export only; default export only; export in declaration; export list; re-export
